# DeviceStore — интернет-магазин цифровой техники

Информационная система (ИС) интернет-магазина цифровой техники на базе **Laravel 12** (backend + REST API) и **Vue 3** (SPA-фронтенд).

## 1. Описание предметной области

Предметной областью ИС является **розничная электронная торговля цифровой техникой и электронными устройствами** (смартфоны, ноутбуки, планшеты, мониторы, аудиотехника, игровые консоли, фототехника, умный дом, аксессуары и периферия).

ИС автоматизирует следующие бизнес-процессы:

- **Ведение каталога товаров** — каждая позиция относится к одной из категорий (20 категорий устройств), имеет название, описание, цену, скидку (в %), количество на складе и изображение.
- **Работа с покупателями** — регистрация и авторизация пользователей (JWT-токены через Laravel Sanctum), ведение профиля и загрузка аватара.
- **Корзина покупок** — добавление товаров в корзину, изменение количества, удаление, привязка к пользователю.
- **Избранное** — формирование пользователем списка понравившихся товаров.
- **Оформление и оплата заказов** — создание заказа из корзины, оплата через платёжную систему **Stripe**, история заказов.
- **Отзывы и рейтинги** — пользователи оставляют отзывы (оценка от 1 до 5, плюсы, минусы, комментарий) на товары; рейтинг товара агрегируется из отзывов.
- **Администрирование** — управление товарами, категориями и контентом через закрытый административный раздел (роль ADMIN).

### Роли пользователей
- **Гость** — просмотр каталога, категорий и детальных страниц товаров.
- **Авторизованный пользователь** — корзина, избранное, отзывы, оформление и оплата заказов, личный кабинет.
- **Администратор (ADMIN)** — полный доступ к управлению каталогом и категориями.

## 2. Основные сущности (модели данных)

| Сущность        | Назначение                                              |
|-----------------|---------------------------------------------------------|
| `User`          | Пользователь системы (покупатель / администратор)       |
| `Role`          | Роль пользователя (связка многие-ко-многим `role_user`)|
| `Profile`       | Профиль пользователя, аватар                            |
| `Category`      | Категория товаров                                       |
| `Product`       | Товар (девайс) с ценой, скидкой, количеством, картинкой |
| `CartProduct`   | Позиция корзины (пользователь ↔ товар + количество)     |
| `Favorite`      | Избранный товар пользователя                            |
| `Order`         | Заказ (сумма, скидка, статус, комментарий)              |
| `order_product` | Строка заказа (товар + количество + цена)               |
| `ProductReview` | Отзыв и оценка товара                                   |

## 3. Технологический стек

- **Backend**: PHP 8.x, Laravel 12, Laravel Sanctum (API-аутентификация), Eloquent ORM, миграции.
- **База данных**: PostgreSQL (по умолчанию), также поддерживается SQLite.
- **Frontend**: Vue 3 (Composition API), Vue Router, Pinia, Vite.
- **Платежи**: Stripe (`@stripe/stripe-js`, `stripe-php`).
- **Хранилище файлов**: локальное (изображения товаров в `public/images/products/`).

## 4. Установка и запуск

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan db:seed
```

Запуск в режиме разработки:

```bash
php artisan serve   # http://localhost:8000
npm run dev         # Vite dev-server, http://localhost:5173
```

### Сидеры (демо-данные)

- `RoleSeeder` — администратор `admin@example.com` (пароль `securepassword`) и роль `ADMIN`.
- `CategorySeeder` — 20 категорий цифровой техники (id 1–20).
- `ProductSeeder` — 28 товаров-девайсов во всех категориях с реальными изображениями (загружены локально в `public/images/products/`), ценами и скидками (в %).

## 5. Основные API-маршруты

| Метод | Маршрут                          | Описание                       |
|-------|----------------------------------|--------------------------------|
| POST  | `/api/register`                  | Регистрация                    |
| POST  | `/api/login`                     | Авторизация                    |
| POST  | `/api/logout`                    | Выход                          |
| GET   | `/api/products`                  | Список товаров                 |
| GET   | `/api/products/{id}`             | Товар по id                    |
| GET   | `/api/categories`                | Список категорий               |
| GET   | `/api/categories/{id}/products`  | Товары категории               |
| GET   | `/api/products/ratings`          | Товары с рейтингами            |
| POST  | `/api/AddCart`                   | Добавить в корзину (auth)      |
| GET   | `/api/cart`                      | Корзина (auth)                 |
| POST  | `/api/favorites/add`             | Добавить в избранное (auth)    |
| POST  | `/api/orders`                    | Создать заказ (auth)           |
| POST  | `/api/products/{id}/reviews`     | Оставить отзыв (auth)          |
| `/admin/*` | Управление товарами и категориями (ADMIN) | Панель администратора |

## 6. Структура ключевых каталогов

```
app/Http/Controllers/   # REST-контроллеры
app/Models/             # Eloquent-модели
app/Services/           # бизнес-логика (ProductService, CategoryService, StripeService)
app/Policies/           # политики доступа
app/Middleware/         # AdminMiddleware (проверка роли ADMIN)
database/migrations/    # схема БД
database/seeders/       # сидеры с демо-данными
resources/js/           # Vue 3 SPA (компоненты каталога, корзины, заказов, админки)
routes/web.php          # все маршруты приложения
public/images/products/ # изображения товаров
```
